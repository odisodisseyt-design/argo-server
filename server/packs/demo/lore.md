# Эхо Поляны

Небольшой тестовый мир: поляна у старого дуба, серый камень и тропа в лес.
Используется только для проверки серверного движка, памяти, пошагового протокола
и data-driven интерфейса. Полноценный мир серии «Моё пространственное убежище»
будет подключён отдельным паком после обсуждения с автором.
